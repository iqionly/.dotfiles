# Installation

Create the folder in this path : `~/.config/nvim`.

And run `git clone git@github.com:iqionly/neovim.git .` or (if using https) `https://github.com/iqionly/neovim.git`.

To enable the highlight, indentation.. you need to ensure run command:
`:TSInstallAll`

If somehow `php`, `blade` not highlighted, try install with `:TSInstallFromGrammar php blade ...`.

Run this after you first open neovim (after trigger installation all plugins needed).
